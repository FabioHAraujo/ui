CodeSnippet lives in its own entry point so that Shiki stays out of bundles that do not need it. Install the optional peer first.

<CodeGroup sync="pm" tabs={[{ label: "bun", code: "bun add shiki" }, { label: "npm", code: "npm i shiki" }, { label: "pnpm", code: "pnpm add shiki" }]} />

```svelte
<script>
  import { CodeSnippet } from "@codeatlasdev/ui/code";
</script>

<CodeSnippet code={source} language="typescript" />
```

The theme switches between a light and a dark high-contrast Shiki theme when the color scheme changes.
