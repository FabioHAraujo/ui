```svelte
<PinInput label="Verification code" bind:value={code} oncomplete={(v) => verify(v)} />
```

One hidden input backs all cells, with `autocomplete="one-time-code"`, so mobile keyboards offer the SMS code. In `numeric` mode the numeric keypad opens and non-digits are rejected. The `error` is announced with `role="alert"`.
