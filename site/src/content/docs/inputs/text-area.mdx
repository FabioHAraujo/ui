```svelte
<script>
  import { TextArea } from "@codeatlasdev/ui";
  let message = $state("");
</script>

<TextArea label="Message" bind:value={message} rows={4} />
```

The label floats when the field has a value or a placeholder. `description` is hidden while an `error` is shown. Text stays at 16px or more on touch devices so iOS Safari does not zoom on focus.
