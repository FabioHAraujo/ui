```svelte
<script>
  import { GlassSurface } from "@codeatlasdev/ui";
</script>

<GlassSurface thickness="thin" tinted>…</GlassSurface>
```

GlassSurface is the low-level material. Prefer [Glass Card](/docs/surfaces/glass-card/) for content containers. Extra attributes are forwarded to the root element. Do not add `will-change: transform` to a glass element or its ancestors, since it breaks `backdrop-filter`.
