## Quick rules that apply everywhere

- Never write layout CSS by hand. Grid, Row, Stack handle it.
- Never use arbitrary colors. Use `--ca-*` semantic tokens.
- Never write a component over 200 lines. Split it.
- Never sound like a language model. Write like a developer.
